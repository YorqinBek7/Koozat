# АННОТАЦИЯ

Данная выпускная квалификационная работа посвящена проектированию и разработке аналитической системы для мониторинга учебного процесса студентов в режиме реального времени. В работе обоснована актуальность отслеживания учебных показателей (посещаемость, оценки, активность) в современных образовательных учреждениях, проанализированы существующие системы (Moodle, Google Classroom) и выявлены их недостатки. Система разработана с использованием технологий Flutter и Firebase и обеспечивает обновление данных в реальном времени, визуальную аналитику и ролевой доступ. В работе рассмотрены архитектура системы, структура базы данных, программные модули, а эффективность системы оценена на основе статистических данных.

**Ключевые слова:** мониторинг в реальном времени, учебная аналитика, Learning Analytics, Flutter, Firebase, Cloud Firestore, образовательные технологии, мобильное приложение, визуализация данных.

# ANNOTATION

This graduation qualification work is devoted to the design and development of an analytics system for monitoring the students’ learning process in real time. The work substantiates the relevance of tracking learning indicators (attendance, grades, activity) in modern educational institutions, analyzes existing systems (Moodle, Google Classroom) and identifies their shortcomings. The system is developed using Flutter and Firebase technologies and provides real-time data updates, visual analytics and role-based access. The work covers the system architecture, database structure, software modules, and evaluates the system’s effectiveness based on statistical data.

**Keywords:** real-time monitoring, learning analytics, Flutter, Firebase, Cloud Firestore, educational technologies, mobile application, data visualization.
